Codex 生图与改图

按 Excel bridge 0.4.6 接入 BPS 独立 Images 接口，复用已选账号的 OAuth。升级插件后，在 Codex 当前 provider 的配置中合并以下请求头；保留原有 base_url、API Key 和其他请求头，不要重复创建相同配置项。

http_headers = { "x-openai-actor-authorization" = "excel-codex-bridge" }

例如 model_provider = "custom" 时，该行属于 [model_providers.custom]。Windows 文件为 %USERPROFILE%\.codex\config.toml，macOS 为 ~/.codex/config.toml。这是客户端提供 image_gen 工具所需的标记，不是新凭据；配置完成后完全退出并重开 Codex。由其他工具管理配置时，请修改对应 provider 配置。

宿主分组需允许生图，gpt-image-2 应能调度到已选 BPS 账号，账号的图片工具策略不能为“拦截”。固定使用 gpt-image-2 / PNG，支持 auto、1024x1024、1536x1024、1024x1536、1280x720；不支持透明背景、蒙版或流式图片。原有图片探测按钮验证识图；生图请在 Codex 中请求一次并在下方查看 Images 诊断。

图片路由诊断

独立保留本实例最近 10 次已结束的识图、生图与改图请求，普通文本请求不会覆盖它们。生图/改图显示 Images 接口状态与输出条目数；识图显示附件及 Responses 状态。识图探测通过不代表生图可用。刷新只读取状态，不发送上游请求。
