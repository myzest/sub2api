- 真实插件可执行文件的 go-plugin 握手、身份/版本校验、HostService v2 broker 回连、
  状态读取与 HTTP 转发。这里的宿主服务和上游均为可控测试夹具。
- 按账号读取模型与 Codex 推理档位；空默认值与显式 `none` 不混淆。
- 2 题 × 2 轮确实发送 4 次请求，并发数为 1，每次唯一会话 ID 与缓存键，
  单条独立输入、无历史、无工具。取消提交请求不会取消后台任务。

- 每账号最新批次替换、重复命令不重复执行、清理后迟到结果不复活。

- 超过 1000 个键的完整扫描与清理；清理中断后的恢复。
- 进程恢复保留已提交回答，未完成项标记中断，删除孤立分片及旧批次。
- 普通转发的请求体、重复响应头、代理、取消传播、不完整响应错误，以及
  `request_sent` 防重放语义。
- 使用宿主原样 CSP 和 `sandbox="allow-scripts"` 的真实浏览器测试：

## 本轮审查修复

- **模型目录竞态**：延迟第一个 A 账号的响应，再依次选择 B、A，原实现会残留旧模型选项。
  增加目录请求版本校验；旧成功和失败响应均不能覆盖当前选择。
- **停用后的过期状态**：插件停止时原弹窗仍保留模型和档位，重启后可能提交旧参数。
  统一清除模型、档位、结果读取状态和缓存，并使未完成的读取失效。
- **最终提交失败后覆盖结果**：注入最后一次索引写入失败，原实现仍允许新任务覆盖 Pending。
  现在拒绝同账号新任务，保留可读结果，提示通过重启恢复或主动清理后再测。
- **测试脚本漏提交**：宿主根 `.gitignore` 的 `tests` 规则会忽略本插件的浏览器与验包脚本。
  只在插件自身 `.gitignore` 中添加例外，并确认两份脚本出现在可提交文件列表中。

前三项均先用新增回归测试复现失败，再验证修复后通过。普通转发、后台串行运行、清理与
重启恢复的已有测试也全部通过；公开 SDK 快照与宿主原文件逐字节一致。

## 重现

在插件根目录执行：

```sh
go mod tidy
go vet ./...
go test -race ./...
go run ./cmd/packager build
node tests/verify-package.cjs
unzip -o -q dist/gpt-inspector-0.1.0.s2plugin -d build/package-check
INSPECTOR_TEST_BINARY="$PWD/build/package-check/runtimes/darwin-arm64/gpt-inspector" go test -race -count=1 ./...
INSPECTOR_UI_DIR="$PWD/build/package-check/ui" npm test
```

根据测试机的平台调整 `INSPECTOR_TEST_BINARY`。浏览器测试截图和示例账号均来自夹具，
不是实际 GPT 账号的智力测试结果。测试浏览器使用软件渲染，避免本机 macOS 无头 GPU
截图遗漏嵌套沙箱 iframe；该选项不进入发布插件。
