# GPT Inspector · Sub2API 账号智力测试插件

选择现有 GPT OAuth 账号，运行固定题目，查看模型原始文字回答和鹈鹕动画。
插件不评分、不标记“正常/降智”，也不调用 manxue.ai 或其他评估服务。

整个插件位于本目录，是独立 Go 模块。运行时只使用现有插件协议；不修改
Sub2API 的前端、后端、数据库结构、依赖或 CSP，不部署额外服务。

## 安装

1. 将 `dist/trusted-publisher.yaml` 中的发布者公钥**合并**到部署现有配置的
   `plugins.trusted_publishers` 映射，保留其他配置，保持 `allow_unsigned: false`。
   首次添加公钥后重启 Sub2API，使信任配置生效。
2. 在管理员「插件管理」页面导入 `dist/gpt-inspector-0.1.0.s2plugin`。
3. 启用插件，再打开其配置弹窗。宿主要求的管理员二次验证、兼容性确认仍按原流程执行。
4. 选择账号，等待模型目录加载；手动选择模型和推理强度，勾选题目、设置轮数后开始。

安装包包含 `linux-amd64`、`linux-arm64`、`darwin-arm64` 独立运行时及全部静态 UI。
容器中无需安装 Go、Node.js、浏览器或额外数据库。公钥信任同一发布者后，后续同签名更新
无需重复配置公钥。同 ID 更新遵循宿主要求：先停用，再导入新版本，最后启用。

当前宿主仅开放 `openai.oauth.outbound_transport.v1`，因此本插件**同时承担普通 OpenAI
OAuth HTTP 出站转发和智力测试**。宿主只有一个此类启用槽位，如已有转发插件，需要先停用
它再启用本插件。普通转发保留请求/响应头和流式响应、使用宿主传入的账号代理，并传播取消。

基于当前工作区 Sub2API 0.2.8 的公开协议构建；要求 HostService v2。清单兼容范围为
`>=0.2.8 <0.3.0`。已验证公开协议、真实插件子进程和模拟上游；尚未进行实际部署的导入及
真实 GPT 账号生成验证，因此未把宿主版本伪标记为已完成真实部署验证。

## 使用规则

- 固定四题：鹈鹕骑自行车 HTML/SVG 动画、摸糖问题、最新苹果手机、日本首相。
  完整原文由插件后端提供，弹窗中可展开查看。
- 题目默认均不选，可单选或多选。每题重复 1–20 轮，串行执行，并发数为 1。
  同时只能运行一个测试批次。例如选 2 题、3 轮，共 6 次独立请求。
- 账号选择后从该账号的 Codex 上游目录读取模型，档位来自该模型的
  `supported_reasoning_levels`。目录错误会明确显示并可重试，不使用默认模型兜底。
  宿主自定义模型映射别名未通过现有插件接口暴露，因此以上游真实模型名显示。
- 模型和推理强度初始为空；切换账号同时清空两者，切换模型清空强度，提交后也清空两者。
  `none` 是可明确选择的有效档位，与“未选择”不同。
  快速切换账号时丢弃过期目录响应；插件停用或进程变化后也清空模型与档位，需重新获取并选择。
- 每条请求独立生成会话 ID、会话头和缓存键，只有当前题目的一条输入消息，
  `store:false`，不带历史、`previous_response_id` 或工具结果，工具列表为空。
  系统指令为「请独立完成用户的任务。不要联网，不使用任何工具。」
- 提交时固定账号、模型、强度、题目和轮数，后续表单修改不会影响当前任务。
- 单题失败记录错误并继续，不自动重试或切换账号。支持停止；已完成与已接收到的部分回答保留。
- 单题超时 5 分钟，回答文本及推理摘要合计上限 2 MiB。超限/中断明确标记为失败或不完整，
  不将截断回答显示为成功。存储不可用时停止批次，避免继续消耗额度而无法保存。

## 后台与结果

任务属于启用后的插件进程。关闭弹窗、刷新页面、关闭浏览器不会取消已提交任务。
再次打开后，在「结果与存储」选择账号、题目及轮次查看。

停用插件、更新插件或重启容器会结束其进程。重新启用后保留已经持久化的回答，
将未完成项目标为“中断”，不自动恢复生成或重放请求。

文字以原文显示；鹈鹕题默认提供动画预览，可切换原始 HTML。预览使用独立
`sandbox="allow-scripts"` 的 `srcdoc` iframe，并增加限制外部资源的 CSP，
不把生成代码注入插件控制页面。保存的模型原文保持不变，预览仅识别并剥离可能出现的
完整 Markdown HTML 代码围栏。模型引用外部资源时，预览会阻止它们加载。

每个账号仅保留最新一个批次，批次包含当次所有题目、所有轮次。
新批次进行中保留上一批，新批次结束后提交新索引并删除旧结果。
若最终索引提交失败，保留上一批和当前批次，并拒绝该账号的新测试，防止覆盖尚未提交的结果。
此时仍可查看已经保存的回答；存储恢复后，停用并重新启用插件以恢复索引，
或主动清理该账号的结果后重新测试。

结果在宿主提供的 Redis KV 内持久化；不保存于浏览器，不持久化 OAuth Token。
账号身份由宿主按需解析，插件不自行刷新 Token。结果能否跨 Redis 数据卷丢失而保留，
取决于现有部署的 Redis 持久化和备份；插件不更改 Redis 配置。

## 存储与清理

- 显示总用量、各账号用量、账号数与已保存回答条数。
- 用量是 KV **值**的实际字节数，包括压缩回答、索引及临时写入；不包含 Redis 键名、
  Redis 内存分配或数据库/AOF 文件开销。
- 回答 gzip 压缩后按 192 KiB 分片，低于宿主单值 256 KiB 上限。
  读取时校验 SHA-256，缺失或损坏的分片会报错，不拼接展示残缺 HTML。
- 「清理此账号」只删除该账号的测试数据。「清空全部结果」删除本插件全部测试数据，
  不删除账号或插件配置，不停用正常转发。
- 清理先记录持久化清理标记、取消受影响任务并阻断迟到写入，再删除数据。
  清理过程中重启时，下次启动继续完成删除。全清循环删除直至无残留，支持超过 1000 个键。
- 启动恢复会清理崩溃留下的未提交分片和旧批次。运行中新旧结果可能短暂同时存在，统计如实计入。

## 现有宿主接口的使用方式

UI 仅通过 `postMessage` Bridge 与宿主通信，不读取管理员 Token，不直接调用管理 API。

`config.save` 保存带唯一 ID 和当前插件实例 ID 的显式命令，紧接着通过 `config.test`
分发。保存/主动命令沿用宿主原有二次验证，宿主的“已保存”提示也保留。
查看批次或回答同样使用这一现有通道，可能触发宿主的验证要求。

`ApplyConfig` 仅校验，无启动任务等副作用。启动、停止、清理命令去重；旧实例或过期命令
不执行。`Health`/`plugin.status` 只读已发布的内存快照，不发上游请求、不启动任务，
不包含完整回答。完整回答由管理员查看时按需读取，避免每次轮询发送全部动画源码。

首版针对**单实例、一个容器**。多个弹窗的保存/执行无法在现有 Bridge 中组成原子事务，
请在一个弹窗内进行操作；UI 检查命令 ID，发现不匹配明确提示。后台仍只允许一个批次。

测试直接使用所选账号的短期身份和代理访问 Codex 上游，消耗该账号的上游额度；
不会经过普通网关的客户端计费/用量日志流程。回答中显示上游返回的 usage。

## 开发与发布

需要 Go 1.26+。Node.js/Playwright 仅用于开发期浏览器测试，不是插件运行依赖。
所有命令均在本插件目录执行。

```sh
go test -race ./...
npm ci
npx playwright install chromium
npm test
```

macOS 浏览器测试默认使用已安装的 Google Chrome。其他平台默认使用 Playwright Chromium；
可设置 `CHROME_BIN` 指定浏览器可执行文件。测试使用隔离临时浏览器配置及模拟账号，
不连接实际 GPT 账号。

首次发布：

```sh
go run ./cmd/packager keygen
go run ./cmd/packager build
```

当前交付已经生成密钥与安装包，**不要重复生成或覆盖密钥**。后续修改后只执行 `build`。
默认私钥保存在 `.signing/publisher.pem`，权限为 0600，已被 Git 忽略，不进入安装包。
请单独保管，用于给后续版本和其他自写插件签名。`-key` 与 `-publisher` 可指定现有发布者：

```sh
go run ./cmd/packager build -key .signing/publisher.pem -publisher gpt-inspector-local-v1
```

定制运行平台：

```sh
go run ./cmd/packager build -targets linux/amd64,linux/arm64,darwin/arm64
```

真实子进程验证（按本机平台调整路径）：

```sh
INSPECTOR_TEST_BINARY="$PWD/build/runtimes/darwin-arm64/gpt-inspector" go test -race ./...
```

`internal/pluginapi` 是当前宿主公开 SDK 的原样快照，来源见该目录 NOTICE。
插件不会通过 `replace`、`go.work` 或依赖宿主私有包构建。

## 文件组织

```text
cmd/gpt-inspector/    插件进程入口
cmd/packager/         密钥生成、交叉编译、清单哈希、Ed25519 签名和打包
internal/pluginapi/  公开协议快照
internal/inspector/  账号目录、模型调用、后台任务、结果存储、透明转发
ui/                  插件弹窗、Bridge、动画隔离预览
tests/               浏览器集成测试
dist/                安装包与公钥配置（生成文件）
.signing/            本地发布私钥（忽略提交）
```
